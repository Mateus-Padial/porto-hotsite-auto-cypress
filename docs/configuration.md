# Configuração — portoseguro-hotsite-auto

Configuração e execução de **Portoseguro Hotsite Auto**.

## Variáveis e Configurações

Configurações sensíveis ficam no **AWS Secrets Manager** (ver `AWS_SECRET_NAME`) e/ou `appsettings.json`. Consulte o README do repositório.

## Execução Local

```sh
npm install && npm start
```
