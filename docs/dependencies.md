# Dependências — portoseguro-hotsite-auto

Dependências e integrações de **Portoseguro Hotsite Auto**.

## Dependências Principais

- chart.js
- dotenv
- open

## Integrações Externas

Integrações típicas da plataforma Vertem: Azure Service Bus / RabbitMQ, SQL Server / MongoDB / Redis, Datadog/Graylog (observabilidade), Vertem.Authorization / vertem.identity (autenticação).
